1. Understanding the Task

Based on analyzing the reference app at campaign-one-pearl.vercel.app, this is a community-funded ad campaign platform:

ConceptDescription
CreatorsWrite campaigns about local/civic issues
Trust Review (UUTS)Fact-check score: fact_check + communication_integrity + shared_reality
BackersFund campaigns; money pays for ad distribution
Ad AmplificationAds run on Facebook, Instagram, YouTube, Reddit, LinkedIn, X, TikTok
Impact Tracking$1 → 27 people reached; views = reach × 1.6

2. Tech Stack

Frontend

  • React Native (Expo SDK 58)
  • TypeScript
  • React Navigation 7 (Stack + Bottom Tabs)
  • Zustand 5 (State Management)
  • Ionicons (Icons)
  • react-native-svg (Charts)

Backend (Demo Mode)

  • No real backend — all local
  • Zustand stores with seed data
  • AsyncStorage for persistence
  • Mock API layer matching reference routes
  • AI generation via local algorithm port
Why this stack? The reference app is React (same paradigm), Expo gives us the fastest APK build path, and the local demo mode approach (matching the reference) means no backend infra needed.

5. Core Algorithms

Trust Score Calculation

// FNV-1a hash for deterministic pseudo-randomness
function fnvHash(str: string, min: number, max: number): number {
  let hash = 2166136261;
  for (let i = 0; i < str.length; i++) {
    hash ^= str.charCodeAt(i);
    hash = Math.imul(hash, 16777619);
  }
  return min + (Math.abs(hash) % (max - min + 1));
}

function calculateTrustScore(campaign) {
  const text = [campaign.title, campaign.long_description,
                campaign.why_backers_should_care].filter(Boolean).join(' ');
  const sourceCount = campaign.campaign_sources?.length ?? 0;

  const factCheck      = Math.min(100, 54 + sourceCount * 9 + fnvHash(text+'f', 0, 14));
  const commIntegrity  = Math.min(100, 61 + fnvHash(text+'c', 0, 28));
  const sharedReality  = Math.min(100, 58 + fnvHash(text+'s', 0, 30));
  const composite      = Math.round(factCheck*0.45 + commIntegrity*0.30 + sharedReality*0.25);

  return {
    composite, fact_check: factCheck,
    communication_integrity: commIntegrity, shared_reality: sharedReality,
    decision: composite >= 70 ? 'accepted' : composite >= 55 ? 'on_hold' : 'rejected',
  };
}

AI Campaign Generation

function generateCampaignContent(issueText: string) {
  const keywords = extractKeywords(issueText);       // top 6 by frequency
  const summary  = extractSummary(issueText);         // first sentence up to 160 chars
  const category = detectCategory(issueText);          // match words to category rules
  const first    = capitalize(keywords[0] || 'This issue');
  const second   = keywords[1] || 'the people affected';

  return {
    title: summary.replace(/[.!?]$/, '').slice(0, 80),
    category,
    tagline: `${first} is not a small problem, and it is a fixable one.`,
    descriptionHtml: `<p>${summary}</p><p>Most people never hear about ${second}...`,
    targetAudience: `People who care about ${keywords.slice(0,2).join(' and ')}`,
    adHeadline: `${first}. The part nobody mentions.`,
    adPrimaryText: `${summary} Here is what the records actually show.`,
    // ... slides, whyBack, etc.
  };
}

Impact Calculation

const REACH_PER_DOLLAR = 27;

function calculateImpact(contributions) {
  const totalCents = contributions.reduce((s, c) => s + c.amount_cents, 0);
  const dollars = totalCents / 100;
  const reach = Math.round(dollars * REACH_PER_DOLLAR);
  return {
    totalCents, dollars, reach,
    views: Math.round(reach * 1.6),
    actions: Math.round(reach * 0.016),
    perceptionShift: 7.4,
  };
}

9. APK Build Instructions

Option A: EAS Build (Recommended)

  1. npm install -g eas-cli
  2. eas login (create account at expo.dev if needed)
  3. eas build -p android --profile preview
  4. Wait ~15 min, download APK from link provided

Option B: Local Build

  1. Install Android Studio + Android SDK
  2. npx expo prebuild
  3. cd android && ./gradlew assembleRelease
  4. APK at android/app/build/outputs/apk/release/

Option C: Expo Dev Build (Quickest for testing)

  1. eas build -p android --profile development
  2. Install development build APK on device
  3. Run npx expo start --dev-client
